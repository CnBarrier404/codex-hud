# Changelog

## v0.1.0-alpha.1

欢迎体验 Codex HUD 的首个 Windows 抢鲜体验版本！

### 新增

- 查看 Codex 5 小时和每周额度的剩余量及重置时间
- 查看当前账号和订阅信息
- 按时间范围查看本地 Token 用量、缓存命中率和各模型的用量
- 从系统托盘打开 HUD，面板显示期间自动刷新数据

当前版本仅提供 Windows x64 可执行文件，需要系统安装 WebView2 Runtime 和 Codex。

---

Welcome to the first early access release of Codex HUD for Windows!

### Added

- View remaining 5-hour and weekly Codex allowances and reset times
- Check account and subscription details
- Explore local token usage, cache hit rates, and usage by model across selectable time ranges
- Access the HUD from the system tray, with automatic refresh while the panel is visible

This release provides a Windows x64 executable only and requires the system WebView2 Runtime and an installed Codex.
